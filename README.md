
# Kitap Okuma ve Paylaşım Uygulaması

Java kullanılarak Android platformu için geliştirilmiş bir kitap okuma ve paylaşım uygulamasıdır.

Uygulama, kullanıcıların kitap okuyabileceği, platforma kitap yükleyebileceği ve diğer kullanıcılarla kitap paylaşabileceği bir ortam sunmaktadır.

## Özellikler

- **Kullanıcı Yönetimi:** E-posta ile hesap oluşturma ve e-posta doğrulama.
- **Kimlik Doğrulama:** Kullanıcı girişi ve parola sıfırlama işlemleri.
- **Profil Yönetimi:** Kullanıcıların kendi profillerini düzenleyebilmesi.
- **Kitap Yönetimi:** Platforma kitap yükleme ve kitap okuma.
- **Favoriler:** Beğenilen kitapları favorilere ekleme.
- **Kitap Arama:** Kitapların kolayca aranabilmesi.
- **Kategori Yönetimi:** Kitap kategorilerinin eklenmesi ve düzenlenmesi.

## Kullanılan Teknolojiler

- Java
- Android
- Firebase Authentication
- Firebase Realtime Database
- Firebase Storage

## Firebase Kullanımı

Projede kullanıcı kimlik doğrulama, veritabanı ve dosya depolama işlemleri için Firebase servislerinden yararlanılmıştır.

## Projenin Amacı

Bu proje, Android mobil uygulama geliştirme, Java programlama dili ve Firebase servislerinin kullanımı konularında deneyim kazanmak amacıyla geliştirilmiştir.
